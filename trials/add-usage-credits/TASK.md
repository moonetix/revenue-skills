The Coinbarn assistant (`POST /api/ask` with `{"prompt": "..."}`, answer streamed back as text) is free right now, and model calls cost us real money. Make it cost coins. Price per question: 1 coin per 100 prompt tokens plus 1 coin per 10 answer tokens, using the token counts the model provider reports, rounded up once per question. Answers stay capped at 400 tokens. Someone without enough coins for the longest possible answer gets a 402 and the model is not called.

If the model fails before it says anything, the question is free; if an answer stops part way, charge for what the user received. The mobile app resends a question with the same `Idempotency-Key` header after a network drop, and that must never ask the model or charge twice. `GET /api/me` -> `balance` should show the coins the user can spend right now. The provider is described in `docs/llm-provider.md` (sandbox: `tools/llm-sandbox.mjs`), model calls time out after `LLM_TIMEOUT_MS`, and `GET /admin/reconcile` must keep reporting no mismatches.
