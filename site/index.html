Skills

One skill finds the bugs. The other {{BUILDERS}} build the parts that prevent them, in your stack and with your conventions. Each skill is a folder of plain Markdown that your agent reads when a task calls for it.

    Install

    The skills follow the open Agent Skills format, so they work with Claude Code, Cursor, Codex, GitHub Copilot, Gemini CLI, OpenCode, Goose, Amp and other agents that read it.

    All skills, with the skills installer
    npx skills add moonetix/revenue-skills
    Only the audit
    npx skills add moonetix/revenue-skills --skill money-audit
    In Claude Code
    /plugin marketplace add moonetix/revenue-skills
/plugin install revenue-skills@revenue-skills
    In a terminal, then pick it under /plugins
    codex plugin marketplace add moonetix/revenue-skills

    Then ask in plain words

    • Audit this project for ways users could get free credits.
    • Our payment webhook sometimes credits an order twice. Find out why and fix it.
    • Add a referral program that cannot be farmed with fake sign-ups.

    Or measure your agent on Coinjar first

    Copy the first version away from the answer key, audit the copy, score it
    git clone https://github.com/moonetix/revenue-skills
cp -r revenue-skills/playground/vulnerable coinjar
# ask your agent: "Run a full money audit of ./coinjar with the money-audit skill."
node revenue-skills/playground/score.mjs coinjar/money-audit/findings.json

    The probe that produces the proofs only talks to 127.0.0.1 unless you name another host, and it needs Node 20 or newer. The skills installer needs Node 22.20 or newer. Nothing is installed besides Markdown and a few small scripts.
